_lown() {
    local -a commands
    commands=(
        'install:Install package from Git URL or spec'
        'remove:Remove installed package'
        'rollback:Restore previous backup executable'
        'sync:Pull latest changes and rebuild package'
        'list:List all installed packages'
        'doctor:Check Lown installation status'
    )
    _describe 'command' commands
}
_lown "$@"

System Architecture

Core Architectural Highlights

01
User-Space Filesystem Sandbox
Zero sudo or root privileges. All operations, cloned source repositories, linked binaries, and state metadata strictly reside in ~/.lown/.
02
Decentralized Git Resolution
No centralized package index. Installs directly from short specs (gh:user/repo), full Git URLs, or local filesystem paths.
03
Atomic Backup & Rollbacks
Before updating binaries, Lown backs up existing executables to .bak. Revert instantly with lown rollback <name>.
04
Machine-Readable Agent API
Built-in --json flags across list and doctor provide clean JSON payloads for AI agents and automated CI scripts.
05
Fallback Shell Installer
Native Go and Rust projects compile out-of-the-box. Custom toolchains execute scripts.install specified in lown.toml.
06
Zero System Dependency Overhead
Compiled as a standalone Go binary. Needs no background daemons, runtime virtual machines, or heavy system libraries.

Execution Pipeline

How Lown Manages Packages

Step 01
Fetch & Clone
Parses specification URI, fetches repository from Git, and places source tree into ~/.lown/apps/<name>.
Step 02
Build Resolution
Detects lown.toml, go.mod, or Cargo.toml. Compiles native release binary inside an isolated directory.
Step 03
Atomic Swap & Link
Copies previous executable to .bak and places new binary into ~/.lown/bin/ with executable permissions.
Step 04
Audit & Sync
Tracks HEAD commit SHAs in manifest database. lown sync pulls updates and rebuilds only when commits change.

Frequently Asked Questions

Answers & Clarifications

Why use Lown instead of standard package managers?
Lown operates completely in user-space without administrative permissions or root access. It doesn't lock you into a central registry and compiles binaries natively from git sources with automatic .bak rollback safety.
How does Lown handle project builds?
Lown inspects target repositories for lown.toml, go.mod, or Cargo.toml. If native Go or Rust specs are found, it compiles release binaries. If a custom build script is specified in lown.toml, it executes the custom install script inside the isolated app directory.
How do I configure my shell PATH for Lown?
Add export PATH="$HOME/.lown/bin:$PATH" to your ~/.zshrc or ~/.bashrc file. You can verify your shell environment anytime by running lown doctor.
Is Lown compatible with AI Coding Agents?
Yes! Lown supports machine-readable --json flags across commands like lown list --json and lown doctor --json, making it seamless for AI agents to inspect, manage, and verify package states programmatically.
