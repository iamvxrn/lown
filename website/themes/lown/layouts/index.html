Why Lown

Built for developers who want clean user-space tools

Sandbox
100% Rootless
Never touches /usr/bin or prompts for sudo. Everything lives inside your home folder at ~/.lown/.
Resolution
Git as the Registry
No central store or lock-in. Pass any Git repository short spec like gh:user/repo or full URL to compile directly from source.
Safety
Instant Rollbacks
Before overwriting binaries during upgrades, Lown automatically preserves the previous build as a .bak binary. Revert instantly with one command.
Automation
Agent-Native JSON
Provides machine-readable --json flags across commands, allowing AI coding assistants and scripts to inspect system state safely.
