Architecture

How Lown orchestrates user-space toolchains

STEP 01
Forge Resolution
Parses specs (gh:, gl:, cb:, sh:) or raw Git HTTPS endpoints to clone into user-space storage.
STEP 02
Build Auto-Detection
Detects Go, Cargo, Revoq, CMake, Makefile, or Autotools configurations dynamically.
STEP 03
User-Space Linking
Compiles binaries directly inside ~/.lown/apps/ and symlinks into ~/.lown/bin/ with 0 root privileges.
STEP 04
Rollback Snapshots
Preserves atomic .bak copies prior to updating, ensuring single-command instant restoration.
Capabilities

Engineered for clean developer environments

SECURITY
100% Rootless Sandbox

DECENTRALIZED
Git as the Registry

Agent-Native JSON API
