Built for clean, rootless binary management

100% Rootless Sandbox

Never prompts for sudo. Cloned repositories, compiled binaries, and backups strictly reside in ~/.lown/.

Git as the Registry

Pass any Git repository short spec like gh:user/repo or full URL to compile directly from source.

Instant Rollbacks

Automatically preserves previous builds as .bak binaries before updates so you can revert anytime.

Agent-Native JSON API

Provides machine-readable --json flags for AI coding assistants and automation scripts.
