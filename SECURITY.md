# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability within Lown, please report it privately to the maintainer rather than opening a public issue.

### Contact
- **Maintainer**: xntas
- **Email**: xntas@proton.me

Please include details about:
- The affected component or subcommand (`install`, `sync`, `builder`, `db`)
- Steps to reproduce the issue
- Potential security implications (e.g. path traversal, unverified script execution)

### Response Timeline
- **Acknowledgement**: Within 48 hours
- **Assessment & Fix**: Security patches will be issued via hotfix releases.
